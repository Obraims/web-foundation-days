# Web Foundations Reflection

Throughout the Web Foundations course, the single most challenging concept for me to master was working with asynchronous JavaScript—specifically understanding Promises, `async/await` syntax, and connecting frontend components to external REST APIs using `fetch`. Initially, managing execution order and handling asynchronous data streams felt abstract and confusing. However, I overcame this hurdle by practicing step-by-step DOM state updates and extensively inspecting API request payloads, headers, and status codes inside browser developer tools. Seeing network responses directly mapped to UI state changes made asynchronous data flows intuitive.

Reflecting on my capstone project and the feedback I received, the primary area I would improve is user-facing error handling and UI loading states. While my core functionality worked as expected, network requests occasionally left the interface feeling unresponsive during high latency. In a future iteration, I would implement explicit loading spinners, disabled button states during pending requests, and friendly contextual error banners so users receive immediate, clear feedback whenever a network call takes longer than expected or encounters a failure.

Moving forward, my next step is to master backend development by learning a server-side framework such as Node.js with Express (or Python with FastAPI/Flask). Building real server applications will allow me to understand how the REST APIs I consumed are designed from the inside out. Additionally, I plan to deepen my relational database knowledge, mastering SQL schemas, indexing strategies, and database optimization techniques to build complete, end-to-end web applications.
